# QA54_IlCarro
Web testing
A training project focused on automated testing for the website "IlCarro".

Project objective: To practice on how to create, execute, and maintain automated UI tests using Python.

Application under test: https://icarro-v1.netlify.app

Technologies used:
-Python — programming language
-Selenium WebDriver — browser automation
-pytest — testing framework
-Google Chrome — browser for test execution
-Git / GitHub — version control system
